# Harness Implementation Plan (plan 1 of the project)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the test bench that every learned model will train in and be scored by. It runs Pasqal's own GLS code as the baseline, reproduces it exactly in our engine, adds the paper-faithful loop, the classical references, and a first emulator calibration.

**Architecture:**
- A small Python package `learned_selection`.
- Pasqal's GLS code is vendored unchanged under `vendor/pasqal_docking/`, and our engine calls its `GreedyMapping` to generate pieces.
- One beam-search function (`run_beam`) takes three injected callables:
  - a generator, which proposes candidate pieces;
  - a piece solver, which solves a piece;
  - a pruner, which keeps branches.
- The code-faithful and paper-faithful loops are two configurations of `run_beam`.
- Later plans plug learned models into the same three slots.

**Tech Stack:** Python 3.12, uv, networkx, OR-Tools CP-SAT, Pulser, pasqal-cloud, pytest.

**Spec:** `docs/superpowers/specs/2026-10-29-learned-piece-selection-design.md`. This plan covers spec section 10, steps 1 to 3. Later plans cover models 1 to 3, the rest of the ladder, the portfolio demo, and the agent.

## Global Constraints

- **Python and packaging.** `requires-python = ">=3.12,<3.13"`, managed with uv. Run everything as `uv run ...`.
- **Vendored code is never edited.** Files under `vendor/pasqal_docking/` are byte-identical to `pasqal-io/Molecular-Docking` at commit `fafb1f2a872cee0f241cfd233346bc53e39cfcca`, with its `LICENSE` kept next to them.
- **Global `random` is off limits.** The vendored code calls `random.seed(0)` inside every `Lattice` and `GreedyMapping`, so our code must never use the module-level `random` functions. Use `random.Random(seed)` instances only.
- **R1.** Every piece committed by the engine passes `is_valid_piece`.
- **R2.** Every final answer is checked to be an independent set of the original graph. If it is not, raise; never return it.
- **R3.**
  - `quantum_runs` counts every subproblem solve, including pieces of 5 nodes or fewer and the final leftover graph.
  - `pasqal_runs` counts only calls to the piece solver, which is Pasqal's convention.
  - Classical time is reported separately.
- **R4.** Decode bitstrings by register insertion order, never by sorted qubit ids.
- **Credentials.** Credentials come only from the macOS Keychain service `pasqal-cloud` (account = the email, password via `security find-generic-password -s pasqal-cloud -w`). Never print, log or write them.
- **Result records.** Every result record carries `family, n, p, seed, method, k, s, l, restarts, lattice, piece_solver, includes_classical_time`.
- **Lattice defaults.** Lattice `fresnel_61` and blockade `6.6` µm.
- **Small-piece threshold.** `small = 5` is the threshold below which pieces and leftovers are brute-forced, matching Pasqal's run script.
- **Prose.** No em dashes in any prose, docstrings, comments or commit messages.
- **Commits.** Commit locally after each task's tests pass. Push to GitHub only after Hamzah confirms.

## Review Focus

1. **The vendored code reseeds the global RNG.** Our seeded functions must give the same answer whether or not GLS ran in between. Owned by Task 3: `test_own_rng_survives_vendored_reseeding`.
2. **Non-integer or non-contiguous node labels.** Later market graphs use ticker strings, and graphs with removed nodes have gaps in their integer labels.
   - Solvers and the engine must work on both.
   - String labels must not make GLS irreproducible. GLS iterates Python sets, and string hashing is randomised per process.
   - Owned by Task 2 (`test_solvers_accept_string_labels`) and Task 3 (`test_engine_on_string_labels`).
3. **Degenerate graphs.** An empty graph, isolated vertices only, a graph no larger than `small`, or a disconnected graph must terminate with the true optimum. Owned by Task 3: `test_engine_degenerate_graphs`.
4. **Beam explosion.**
   - Pasqal's loop never counts small-piece children toward pruning. A graph made mostly of small pieces (sparse market graphs at a high threshold, with many isolated stocks) multiplies branches by k every round, and nothing prunes them.
   - The engine must refuse with a clear error rather than hang.
   - Owned by Task 3: `test_engine_refuses_beam_explosion`.
5. **A piece solver returning fewer than s sets.** This happens when a piece has only one maximal set. The engine must branch on what it gets. Owned by Task 3: `test_engine_accepts_short_solver_output`.

- [ ] **Step 3: Implement `learned_selection/instances.py` and `learned_selection/solvers.py`**

- `erdos_renyi`: `nx.gnp_random_graph(n, p, seed=seed)`, then `nx.set_node_attributes(G, 1, "weight")`.
- `exact_mis`:
  1. Build a CP-SAT model over an index map of `list(graph)`, so any hashable label works.
  2. Add one Bool per node and `x_u + x_v <= 1` per edge, and maximise the sum.
  3. Set `max_time_in_seconds = time_limit_s` and `num_workers = 8`.
  4. `proven = status == OPTIMAL`.
- `top_maximal_sets`:
  1. Use the same model, plus maximality: `x_v + sum(x_u for u in N(v)) >= 1` for each v.
  2. Solve to optimality.
  3. Record the set S, then add the no-good `sum(1 - x_i for i in S) + sum(x_j for j not in S) >= 1`, and repeat up to s times.
  4. Stop early if infeasible.
  5. Assert that every solve is OPTIMAL; pieces have at most 61 nodes.
- `first_maximum_set`: port the vendored backtracking order exactly, which is include-first DFS over `list(graph.nodes())` that keeps the first subset of strictly greater size. Exponential cost is fine, because it only ever sees graphs of 5 nodes or fewer outside this test.
- `min_degree_greedy`:
  1. Loop: pick the minimum-degree vertex of the remaining graph, breaking ties with `rng.choice` over the tied vertices sorted by `repr`, where `rng = random.Random(seed)`.
  2. Remove it and its neighbours.
- `repair`:
  1. While the set has a conflict, drop the vertex with the most in-set neighbours (ties broken by lowest `repr`).
  2. Then add vertices that have no neighbour in the set, in ascending degree (ties broken by `repr`).

### Task 3: The beam engine, code-faithful, matching Pasqal's output exactly

**Files:**
- Create: `learned_selection/engine.py`
- Test: `tests/test_engine.py`

**Interfaces:**
- Consumes:
  - `GreedyMapping`, `Lattice`, `greedy_subgraph_solver_vv`, `weighted_generate_different_mis` (Task 1)
  - `load_coords`, `lattice_graph`, `is_valid_piece`, `BLOCKADE_UM` (Task 1)
  - `first_maximum_set`, `is_independent`, `top_maximal_sets`, `min_degree_greedy` (Task 2)
- Produces, in `learned_selection.engine`:
  - **Type aliases:**
    - `Mapping = dict` (graph node to trap id)
    - `Generator = Callable[[nx.Graph, int], list[Mapping]]` (the current graph and k, returning up to k candidate pieces)
    - `PieceSolver = Callable[[nx.Graph, Mapping, int], list[frozenset]]` (the induced piece in graph labels, its mapping and s, returning up to s independent sets of the piece)
    - `Branch = tuple[nx.Graph, list]` (remaining graph, partial solution in insertion order)
    - `Pruner = Callable[[list[Branch], int], list[Branch]]` (next level and the number of solver children added this level, returning the kept branches)
  - **`RunResult` dataclass** with the fields `solution: frozenset`, `size: int`, `quantum_runs: int`, `pasqal_runs: int`, `atoms: int`, `rounds: int`, `classical_s: float` and `solver_s: float`.
    - `atoms` is the sum of piece sizes over piece-solver calls.
    - `classical_s` is the wall time minus `solver_s`.
  - **`gls_generator(coords=None, blockade=BLOCKADE_UM, seed=0) -> Generator`** reproduces vendored `obtain_embeddable_subgraphs`. Passing `coords=None` means `load_coords()`, here and in every later function.
    1. Build one `Lattice(coords, blockade, seed=seed)` up front.
    2. For every `v in g.nodes()`, run `GreedyMapping(g, copy.deepcopy(lattice), [], seed=seed).generate_greedy_ud_subgraph_with(v)`.
    3. Stable-sort the results by `len` descending and keep the first k.
  - **`pasqal_greedy_piece_solver(coords=None, blockade=BLOCKADE_UM) -> PieceSolver`** is an adapter around the vendored `weighted_generate_different_mis`:
    1. Build `Lattice(coords, blockade)` once, when the adapter is created. Building it per call would reseed the global RNG between Pasqal's mapping and solving steps, and break the exact match.
    2. Build the lattice-labelled piece with `greedy_subgraph_solver_vv.generate_graph_to_solve(None, piece, lattice.lattice, mapping)` (the method never touches `self`).
    3. Call the vendored function with `(that graph, coords, s)`.
    4. Map the trap ids back through the inverse mapping, preserving list order and keeping duplicates.
    - This adapter exists only to test against Pasqal's output exactly.
  - **`exact_piece_solver: PieceSolver`** is `lambda piece, mapping, s: top_maximal_sets(piece, s)`.
  - **`code_prune(k: int, l: int) -> Pruner`** keeps a running counter across calls. It adds each call's solver-children count, and when the counter is over l it stable-sorts by `len(solution)` descending, keeps the first k, and resets the counter to 0. Otherwise it returns the level unchanged.
  - **`run_beam(graph, generate, solve, k, s, prune, small=5, max_branches=10_000) -> RunResult`**
    - If `list(graph) == list(range(len(graph)))`, use the graph as-is. The exact-match test depends on the original adjacency order.
    - Otherwise, relabel with `nx.convert_node_labels_to_integers(graph, label_attribute="orig")`.
    - Run on the relabelled graph and map the solution back to the original labels. Vendored GLS iterates Python sets, and string hashing is randomised per process, so this keeps string-labelled runs reproducible.
    - Raise `RuntimeError("beam exploded: ...")` as soon as a level holds more than `max_branches` branches.
  - **`run_code_faithful(graph, k, s, l, solve=exact_piece_solver, seed=0, small=5) -> RunResult`** is `run_beam(graph, gls_generator(seed=seed), solve, k, s, code_prune(k, l), small)`.

The `run_beam` loop must mirror vendored `solve_breadthfirst` line for line, because the exact-match test depends on the order of calls into the global RNG:

```
queue = [(graph, [])]; best = []
while queue:
    next_level = []; children = 0
    for g, sol in queue:
        if len(g) <= small:
            if len(g): quantum_runs += 1
            total = sol + first_maximum_set(g)
            if len(total) > len(best): best = total
            continue
        for m in generate(g, k):                      # all mappings first, then solve: RNG order
            assert is_valid_piece(g, m, L)            # R1
            piece = g.subgraph(m)
            quantum_runs += 1
            if piece.number_of_nodes() <= small:
                S = first_maximum_set(piece)
                next_level.append((remove_closed_nbhd(g, S), sol + S)); continue
            pasqal_runs += 1; atoms += len(m)
            for S in solve(piece, m, s):              # time this call into solver_s
                next_level.append((remove_closed_nbhd(g, S), sol + list(S))); children += 1
    queue = prune(next_level, children); rounds += 1
if not is_independent(graph, best): raise AssertionError    # R2
```

Here `remove_closed_nbhd(g, S)` is a copy of g with S and all neighbours of S removed, as in vendored `remove_mis_open_neighborhood_nodes_from_graph`.

### Task 4: Paper-faithful loop and restarts

**Files:**
- Modify: `learned_selection/engine.py`
- Test: `tests/test_paper_loop.py`

**Interfaces:**
- Consumes: `run_beam`, `RunResult`, `Generator`, `Pruner`, `exact_piece_solver`, `gls_generator` (Task 3); `CENTER_TRAP` (Task 1)
- Produces:
  - **`CenterSeededMapping(GreedyMapping)`** overrides only `initialize_mapping`, placing the starting node on `CENTER_TRAP` instead of the code's `int(n/2 + int(sqrt(n))/4)` (trap 32).
  - **`paper_generator(coords=None, blockade=BLOCKADE_UM, seed=0) -> Generator`**:
    - Use one `rng = random.Random(seed)` per generator.
    - Each call samples `min(k, len(g))` distinct start vertices with `rng.sample(sorted(g, key=repr), ...)`.
    - It grows each start with `CenterSeededMapping(g, deepcopy(lattice), [], seed=rng.randrange(2**31))`.
    - It returns the mappings in sample order.
    - The ranking score stays the vendored one, because the paper does not pin the sort direction (spec section 5).
  - **`paper_prune(l: int) -> Pruner`** always stable-sorts by `len(solution)` descending and keeps the first l.
  - **`run_paper_faithful(graph, k, s, l, solve=exact_piece_solver, seed=0, small=5) -> RunResult`**
  - **`best_of_restarts(run: Callable[[int], RunResult], restarts: int) -> RunResult`**:
    - Calls `run(seed)` for `seed in range(restarts)`.
    - Returns the best solution by size, with ties going to the earlier seed.
    - `quantum_runs`, `pasqal_runs`, `atoms`, `rounds`, `classical_s` and `solver_s` are summed over all restarts.

  - `repair`, `is_independent`, `top_maximal_sets` (Task 2)
  - `load_coords` (Task 1)
- Produces, in `learned_selection.cloud`:
  - `client() -> PasqalCloudClient`:
    - Reads the Keychain.
    - Uses `from pasqal_cloud.pasqal_cloud_client import PasqalCloudClient` with `project_id = "6c44ee19-cbf0-4355-934f-4825f40cca40"`.
  - `load_device() -> pulser.devices.Device` deserialises `learned_selection/data/fresnel_device.json`.
  - `trap_map(device) -> dict[int, int]` maps our `fresnel_61` trap id to the device's calibrated-layout trap id, matching coordinates within 1e-3 µm.
  - `piece_sequence(piece: nx.Graph, mapping: Mapping, device) -> pulser.Sequence`:
    - The register is `layout.define_register(*[trap_map[mapping[v]] for v in piece], qubit_ids=[str(v) for v in piece])`.
    - It adds one `Pulse(InterpolatedWaveform(4000, OMEGA), InterpolatedWaveform(4000, DELTA), 0)` on `rydberg_global`.
    - `OMEGA = [1e-9, 4.850055051963065, 12.566370614359172, 11.882582923954192, 1e-9]` and `DELTA = [-D, -23.735663070454464, 2.429518510655143, 13.330733571729787, 31.06390344878028]`. These are Pasqal's schedule from `quantum_solver_molecular.py`, without DMM, since the weights are 1.
    - `D = min(125.66370614359172, channel.max_abs_detuning)`, and OMEGA is clipped to `channel.max_amp`.
  - `decode(bitstring: str, qubit_ids: list[str]) -> list[str]` returns the ids whose bit is 1, using position i maps to `qubit_ids[i]` in register insertion order (R4).
  - **`CloudPieceSolver(PieceSolver)`**:
    - `__init__(self, client, device, emulator=EmulatorType.EMU_MPS, runs=500)`.
    - `__call__(piece, mapping, s)`:
      1. Submit `client.create_batch(seq.to_abstract_repr(), jobs=[{"runs": runs}], emulator=emulator, wait=True)`.
      2. Decode every bitstring.
      3. Map ids back to piece nodes.
      4. `repair` each.
      5. Merge duplicates by summing counts.
      6. Return the s most frequent sets.
    - `.log: list[dict]` gets one entry per call: `n_atoms`, `invalid_rate` (the fraction of shots that are not independent before repair), `top1_size` and `best_size`.
